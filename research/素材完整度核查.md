# 补录素材完整度核查

> 核查时间：本轮 B 阶段补录前。用途：确认各素材源提供的到底是「完整旁白」还是「精选段落」，避免向用户夸大补录成果。

## 结论

三个可用素材源提供的**都不是节目完整旁白**，而是流传最广的精选段落。节目实际时长 50–107 分钟，完整旁白通常数千字；素材源最多给到 300–700 字/期。

|---|---|---|---|---|
| 游民星空 `871270`（23 分页） | ✓ HTTP 200 | 21 期 | 43–297 字 | 精选段落，非全文 |
| 网易号 `E3E1B2TT` | ✓ HTTP 200 | 13 段 | 约 60–150 字/段 | 精选段落，带期名标注 |
| 网易号 `DNVDPDAT` | ✓ HTTP 200 | 约 23 期 | 个别期达 700+ 字 | 精选段落，部分较长 |

## 对交付的影响

- 「已有文案」的期数会增加，但**每期内容仍非节目完整旁白**。
- 文档中据实标注为「补录段落」而非「完整旁白」，不误导。
- 真正要拿到某一期的完整旁白，唯一可靠途径是**观看该期视频并转录**（B 站/CCTV 有整期），这超出本次范围。
